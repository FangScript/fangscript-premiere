# Home Page Visual Upgrade

## Goal
Bring the FangScript home page closer to the shared reference’s polished, cinematic quality while keeping the reference image itself out of the site.

## Changes
- Replace the abstract project placeholders with six distinct, detailed project preview images that read like real websites, dashboards, assistants, and automation products.
- Use those previews consistently in the hero device mockups and featured-project carousel.
- Give services and technology recognizable, purpose-specific icons instead of repeated generic symbols.
- Refine home-page spacing, visual hierarchy, borders, lighting, device framing, and section density to better match the reference.
- Preserve the existing filters, carousel controls, swipe, keyboard access, native page scrolling, responsive layouts, and reduced-motion behavior.

## Technical details
- Generate original project artwork in the project assets folder; do not embed the uploaded reference.
- Keep imagery optimized and lazy-load below-the-fold project previews.
- Update the existing React home component and semantic CSS tokens/styles only where needed.
- Verify desktop and mobile rendering, carousel/filter interactions, and the final build.
